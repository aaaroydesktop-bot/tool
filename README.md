# NetScan - Advanced Termux Network Scanner

A fast and colorful network scanning tool built with Python for Termux.

## Features
- Get Local Network IP Address
- Fast Multi-threaded Port Scanning (Scans top 1024 ports)
- Global command execution (`netscan`)
- Cyberpunk/Neon terminal UI

## Installation in Termux

Run the following commands in your Termux:
```bash
git clone [https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git](https://github.com/aaaroydesktop-bot/tool)
cd YOUR_REPO_NAME
bash install.sh
